# Medicina UDLAP

App de Mac con el repositorio de estudio de la carrera de Medicina de Marcos David Reinah Guzmán (UDLAP).

- `site/` es la copia más reciente de la página. La app la trae adentro para funcionar sin internet y, cuando hay conexión, baja de aquí solo los archivos que cambiaron (`site/manifest.json`).
- `main.js` es la app (Electron).
